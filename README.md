# Coding Tech Landscape

An interactive beginner's roadmap to the world of coding technologies.

## What it does
- Browse 300+ tech tools organized by category
- Search any technology instantly
- Filter by career path (Frontend, Backend, DevOps, AI, etc.)
- Click any card to see what it's used for

## Why I made this
I kept seeing all these tool names (Docker, Kubernetes, GraphQL...) 
and had no idea what half of them did. So I built this to help 
myself (and other beginners) make sense of it all.

## Tech used
- Plain HTML, CSS, JavaScript (no frameworks)
- Devicon & Simple Icons for logos

## How to use
Just open `index.html` in your browser. That's it.
